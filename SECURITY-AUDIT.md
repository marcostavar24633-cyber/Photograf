# Аудит безопасности — PHOTOGRAF

Дата проверки: 2026-11-15
Проверенная версия: `main` на момент аудита
Тип проверки: статический анализ HTML, JavaScript и конфигурации репозитория. Это не пентест и не сертификация безопасности.

## Архитектура и границы защиты

- Сайт — статический проект на GitHub Pages.
- Серверной части, базы данных и API для приёма заявок в проекте не обнаружено.
- Форма заявки работает на стороне браузера: формирует текст и использует буфер обмена; не отправляет заявку на сервер.
- Секреты и ключи API в клиентский код добавлять нельзя: любой опубликованный в репозитории секрет доступен посетителям.
- GitHub Pages не предоставляет произвольную настройку HTTP response headers через файл `_headers`. Такой файл в репозитории не найден; добавлять его как будто он действует на GitHub Pages нельзя.

## Результаты статической проверки

- Не обнаружены вызовы `eval()`, конструктор `new Function()`, `document.write()`, `fetch()` и `XMLHttpRequest` в коде сайта.
- Найденные присваивания `innerHTML` в `gallery-experience.js` и `nav-modes.js` формируют фиксированную статическую разметку/строку интерфейса. Не подставлять в эти места пользовательский ввод или непроверенные внешние данные.
- Внешние сетевые подключения страницы ограничены Google Fonts (`fonts.googleapis.com` и `fonts.gstatic.com`). Остальные изображения загружаются локально из репозитория.
- Ссылка на страницу конфиденциальности с `target="_blank"` содержит `rel="noopener"`.
- У главной страницы есть `meta name="referrer" content="strict-origin-when-cross-origin"`.
- Аналитические счётчики не подключены; идентификатор Метрики остаётся нулевым.
- Форма не имеет внешнего endpoint и не отправляет POST-запросы.

## Ограничения и оставшиеся риски

1. **HTTP security headers не подтверждены.** На GitHub Pages нельзя считать, что `_headers` задаёт CSP, HSTS, X-Content-Type-Options, Permissions-Policy или frame-ancestors. Для этих заголовков нужен хостинг/CDN, позволяющий управлять HTTP-ответами, либо отдельный reverse proxy.
2. **Content Security Policy не настроена.** На странице есть inline CSS и JavaScript, поэтому строгую CSP нельзя добавлять без подготовки nonce/hash или рефакторинга inline-кода. Не включать широкую политику с `unsafe-eval`; если потребуется временный переходный режим, отдельно оценить `unsafe-inline`.
3. **Google Fonts — внешний поставщик.** При загрузке шрифтов браузер обращается к Google. Для минимизации внешних запросов можно локально разместить лицензированные файлы шрифтов и убрать preconnect/stylesheet Google Fonts.
4. **Форма не является системой приёма заявок.** Для реального приёма потребуется отдельный защищённый backend или проверенный сервис форм, политика хранения данных, защита от спама и обновлённое уведомление о конфиденциальности.
5. **Демонстрационный контент и изображения.** Проверка безопасности не подтверждает права на фото, подлинность отзывов, цены, биографию или контакты. См. `ASSET-REGISTER.md`.

## Рекомендации перед коммерческим запуском

- [ ] Сохранить статическую архитектуру, пока backend не требуется.
- [ ] При необходимости реальной отправки заявок выбрать сервис/сервер с TLS, ограничением частоты, антиспамом и минимизацией собираемых данных.
- [ ] Если требуются строгие HTTP-заголовки, выбрать CDN/хостинг, который действительно позволяет задавать их; затем проверить заголовки публичного ответа.
- [ ] При внедрении CSP вынести inline-скрипты и стили либо сформировать корректные хеши/nonce и проверить все ресурсы.
- [ ] Решить, оставить ли Google Fonts или локально разместить файлы шрифтов.
- [ ] Повторить аудит после подключения любых внешних интеграций.
- [ ] Не публиковать секреты, приватные токены и персональные данные в HTML, JS или публичном GitHub-репозитории.

## Итог

На момент проверки не выявлены очевидные опасные динамические исполнители кода или сетевые отправки данных формы. Основные ограничения связаны с моделью статического хостинга: произвольные HTTP security headers не подтверждены, CSP отсутствует, а форма не отправляет заявки. Это зафиксированные ограничения, а не основание заявлять о полном отсутствии рисков.
