# Лендинг фотографа «Вера Ланская»

Одностраничный премиальный лендинг фотографа: сначала портфолио, затем услуги и пакеты, в конце форма заявки.

**Стек:** один файл `index.html` (HTML5 + CSS + чистый JavaScript), без фреймворков и сборки.

## Что внутри

- Hero-слайдер на весь экран с плавной сменой кадров
- Портфолио: masonry-сетка из 26 фото, фильтры по 5 темам (Свадьбы, Love Story, Семья, Портрет, В ожидании), лайтбокс со стрелками, свайпами и Esc
- Блок «Обо мне» с анимированными счётчиками
- 3 пакета услуг; выбранный пакет подставляется в форму
- Этапы работы, слайдер отзывов, FAQ-аккордеон
- Форма заявки: маска телефона и валидация; отправка только через Formspree при настройке ID, иначе форма остаётся в демо-режиме
- Плавающая кнопка мессенджера, липкая кнопка брони на мобильных
- Цели Яндекс.Метрики (`data-goal`), Open Graph, Schema.org, учёт `prefers-reduced-motion`

## Фото

Фото взяты с [Unsplash](https://unsplash.com) (бесплатная лицензия Unsplash) и подключены ссылками.
Чтобы хранить их локально в папке `img/`, запустите на Windows `Скачать фото.bat`: скрипт скачает фото в WebP и перепишет ссылки в `index.html`.

## Перед публикацией

1. Замените фото: места помечены комментарием `<!-- ЗАМЕНИТЬ ФОТО -->`.
2. Укажите имя, телефон, Telegram, WhatsApp, домен и цены (в том числе в Schema.org в `<head>`).
3. Замените примеры отзывов реальными.
4. При необходимости укажите только `FORMSPREE_ID` в `CONFIG`. Telegram Bot API из браузерного кода удалён: токены бота нельзя публиковать в HTML/JavaScript. Для Telegram используйте серверный прокси с секретом в переменных окружения.
5. `privacy.html` содержит уведомление для демонстрационного проекта. Перед реальным сбором заявок замените его полноценной политикой оператора с фактическими сведениями о владельце, целях, основаниях, сроках хранения и получателях данных.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → Save.
Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Автосохранение на GitHub (Windows)

1. Установите [Git for Windows](https://git-scm.com/download/win).
2. Положите `autosave.ps1` и `Автосохранение.bat` в папку с сайтом и запустите `Автосохранение.bat`.
3. При первой отправке откроется окно входа в GitHub: войдите один раз, дальше вход запомнится.

Пока окно открыто, каждое сохранение файлов в папке через ~10 секунд уходит в репозиторий отдельным коммитом, а изменения с GitHub подтягиваются каждые 2 минуты.
