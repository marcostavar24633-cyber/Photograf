# Photograf — премиальный демонстрационный сайт фотографа

Одностраничный адаптивный сайт в концепции **Vera Lanskaya Photography**. Это демонстрационный образ: имя, биография, город, цены, сроки и истории не подтверждают сведения о реальном фотографе или действующем бизнесе.

**Публичная версия:** https://marcostavar24633-cyber.github.io/Photograf/  
**Репозиторий:** https://github.com/marcostavar24633-cyber/Photograf

## Технологии

- HTML5, CSS и чистый JavaScript без фреймворков и этапа сборки.
- Основной документ: `index.html`; визуальные стили: `luxury.css`.
- Локальные изображения в `img/`.
- Playwright для браузерных проверок; axe-core для автоматического аудита доступности.
- GitHub Actions для запуска тестов и публикации через GitHub Pages.

## Концепция и интерфейс

Визуальная система **Luxury Editorial**: кинематографичная обложка, тёмная палитра с оттенками ivory и шампань, журнальная типографика, редакционная сетка портфолио, выразительные переходы и скруглённые элементы управления.

Основные разделы и функции:
- адаптивная навигация и мобильное выдвижное меню;
- полноэкранная обложка со сменой кадров;
- портфолио с тематическими фильтрами;
- просмотр фотографий в лайтбоксе, навигация стрелками, свайпами и клавишей Esc;
- блок авторского подхода;
- демонстрационные пакеты и этапы работы;
- FAQ;
- форма подготовки сообщения с проверкой введённых данных;
- ссылка на уведомление о конфиденциальности.

## Форма и приватность

Форма **не отправляет заявки на сервер и не сохраняет их в базе данных**. После валидации сайт формирует текст заявки и предлагает скопировать его в буфер обмена. Посетитель самостоятельно отправляет сообщение выбранным способом. Если API буфера обмена недоступен, предусмотрен резервный сценарий копирования.

Яндекс.Метрика отключена (`METRIKA_ID: 0`). Не подключены CRM, база заявок и серверная обработка формы. Подробности о локальной работе формы и внешних ресурсах описаны в [privacy.html](privacy.html).

## SEO и индексация

В текущей версии подготовлены title, description, canonical, Open Graph, Twitter metadata, Schema.org, `robots.txt` и `sitemap.xml`. Страница намеренно закрыта от индексации (`noindex,follow`), пока демонстрационные имя, тексты, цены, изображения и сведения о специалисте не заменены и не подтверждены владельцем. Перед запуском продвижения обновите robots meta и проверьте фактические данные.

## Изображения и права

Изображения хранятся локально в `img/`. Наличие файлов в репозитории не подтверждает авторство или лицензию. Перед коммерческим использованием проверьте происхождение и разрешения на каждое изображение либо замените их собственными материалами с подтверждёнными правами.

## Перед коммерческим запуском

1. Замените демонстрационное имя, биографию, город, описание услуг и все неподтверждённые сведения.
2. Используйте только фотографии, на которые есть необходимые права и согласия.
3. Укажите реальные способы связи: телефон, мессенджеры и электронную почту — если они нужны.
4. Проверьте цены, состав пакетов, сроки и условия работы.
5. Если появится реальная отправка заявок или аналитика, отдельно спроектируйте безопасную серверную интеграцию, обновите уведомление о конфиденциальности и проверьте требования применимого законодательства.
6. Перед запуском убедитесь, что canonical, Open Graph и Schema.org содержат актуальный домен и достоверные сведения.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`, корневая папка репозитория. Настройки: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

## Автоматические проверки

Браузерные тесты проверяют структуру страницы, внутренние якоря и локальные изображения, мобильную навигацию, фильтры портфолио, лайтбокс, защитные настройки формы и отсутствие ошибок JavaScript/горизонтальной прокрутки. Отдельно запускается axe-core аудит WCAG для основной страницы и открытого меню.

Локальный запуск:

```bash
npm install
npx playwright install chromium
npm run test:e2e
```

GitHub Actions запускает проверки при изменениях в репозитории. Результаты и скриншоты доступны в разделе [Actions](https://github.com/marcostavar24633-cyber/Photograf/actions).
